## Overview

This program lets you manipulate RNG to craft sigils with specified skills and point ranges. It's standalone and does not interact with the game in any way, other than prompting you for information.

This will not let you snipe sigils with specific point values within ranges. The roll for a value within a range uses a different RNG that's not as controllable or predictable.

Cheap and/or predictable sigil recipes are used to advance the RNG to before the desired sigil, which lets you use very few of the materials used to craft the sigil you're sniping.

The game uses Unix timestamps from the server, this uses timestamps from your system. If those timestamps are out of sync, you can use the find desync tab

Regardless of overall time sync, you can expect the game's timestamp to be slightly behind your system's. It's recommended to feel out the timing with some 0 search depth snipes.
